# Software_2027
BYU Racing software package for the 2026-2027 competition year. The organization is as follows:

## Docs
Contains the software syntax guide and the software development rullset. Newcomers to the project should look over these documents first before begining to work on the project. The syntax guide details the required format of code, while the software development rullset contains general project workflow guidelines and suggestions, including how this project should be organized as a whole.

Other documents should go here that pertain to the entire software team.


## Shared
The shared folder contains files shared across mulitple projects.
